# PeakNet Tenant Access 5.4.1

This maintenance update improves the Session Workspace sidebar layout.

- Widens the left workspace menu so all four portal buttons fit comfortably.
- Adds a clear gutter between menu controls and the vertical scrollbar.
- Rebalances the spacing between the sidebar and customer tenant list.
- Prevents the Security button and management controls from being clipped.

The update remains signed and is verified by the app before installation.
